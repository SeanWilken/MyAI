# MyAI Knowledge Index

This directory is the starting knowledge index for the MyAI application suite.

It is meant to act as a general reference layer that can expand into product strategy, application definitions, feature references, positioning, onboarding, and operating knowledge over time.

## Purpose

- Create one shared source of truth for the suite.
- Separate platform foundation from application-specific behavior.
- Capture working product language, positioning, and feature boundaries.
- Provide reusable references for future site copy, product briefs, and implementation planning.

## Document Map

- `01-platform-overview.md`: suite-level positioning, narrative, and architecture framing.
- `02-product-map.md`: product categories and how the apps fit together.
- `03-core-myaide-handoff-checklist.md`: cross-repo implementation and coordination checklist.
- `04-air-runtime-alignment.md`: AIR framing, responsibilities, and rollout phases.
- `apps/core.md`: MyAI Core reference.
- `apps/studio.md`: MyAI Studio reference.
- `apps/council.md`: MyAI Council reference.
- `apps/aide.md`: MyAI AIDE reference.
- `apps/knowledger.md`: MyAI KnowLedger reference.
- `apps/craft.md`: MyAI UI / Craft reference.
- `apps/iba.md`: MyAI IBA reference.
- `apps/illuminate.md`: GeneralProcedureScript / Illuminate reference.

## Current Notes

- Naming is still partially in working-name mode.
- `GeneralProcedureScript` and `Illuminate` are documented together for now.
- `MyAI Navigator` is captured as a possible future product-facing app name.
