# MyAI UI / Craft

## One-Line Definition

The shared experience system for the MyAI suite.

## Positioning

Craft centralizes UI components, workspace patterns, design tokens, and interaction models so every MyAI application feels connected while remaining specialized.

This is not just a component library. It is the shared interaction system that allows the suite to have overlapping capabilities without feeling fragmented.

## Responsibilities

- keep the suite visually and behaviorally consistent
- centralize reusable interaction primitives
- reduce duplicated frontend patterns across applications

## Features

- design tokens
- theme system
- shared navigation
- app shell layouts
- cards, panels, drawers, and modals
- chat and thread components
- persona cards
- stepper and walkthrough components
- node canvas
- knowledge map
- code and editor wrappers
- artifact previews
- document viewers
- permission badges
- app switcher
- Storybook documentation

## Strategic Role

Apps can overlap because the underlying components are centralized. Craft is how the suite avoids six different chat UIs, permission badges, and workspace layouts.
