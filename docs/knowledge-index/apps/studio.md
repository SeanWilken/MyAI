# MyAI Studio

## One-Line Definition

The control plane for configuration, governance, and administration.

## Positioning

Studio gives administrators a focused control plane for managing organizations, teams, users, personas, policy templates, and application access grants across the suite.

## Responsibilities

- manage organizational structure and access
- control persona creation, runtime defaults, versioning, and deployment
- define org defaults for visibility, uploads, and sharing policy
- configure app access grants per application (KnowLedger, Council, MyAIDE)
- enforce org-scoped operating context before sensitive operations
- expose visibility into platform configuration changes

## Features

- organization, department, team, and user management
- RBAC and policy configuration
- application-level access grants by org
- user invites and onboarding
- persona creation, review, approval, and deployment
- runtime provider/model defaults with profile fallback
- version history and rollback
- governance policy templates (human-readable)
- document visibility and sharing defaults
- uploader and restricted/private creator controls
- explain-access and policy debug surfaces for admins
- org-context switch integration with Core token flow

## Strategic Role

Studio is where organizations define how the entire MyAI suite behaves without editing backend services directly: who can access what, which apps are enabled, and how personas run in production.
