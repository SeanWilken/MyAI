# GeneralProcedureScript / Illuminate

## One-Line Definition

Guided execution that turns completed work into reusable knowledge.

## Positioning

GeneralProcedureScript uses the Illuminate experience mode to guide users through tasks step by step, capture what they did, and generate SOPs, cheatsheets, or reusable learning artifacts.

This product is not normal chat. It should help users complete a task without just handing them a copy-paste answer.

## Naming Model

Current working split:

- `GeneralProcedureScript`: the guided execution application or workflow engine.
- `Illuminate`: the guided walkthrough mode.

Possible product-facing split later:

- `MyAI Navigator`: the application.
- `Illuminate`: the experience mode.

## Core Idea

Instead of giving users the answer immediately, Illuminate breaks the goal into guided steps, adapts to the user’s knowledge level, captures what they did, and produces a reusable SOP, cheatsheet, or reference document afterward.

## Experience Constraints

- best for 1:1 sessions
- works with a persona or personal assistant
- captures the user’s task
- asks enough to gauge user knowledge
- breaks the goal into digestible steps
- forces active completion
- marks each step or slide complete
- summarizes what was done
- exports to Knowledge Hub or KnowLedger
- creates reusable SOPs, cheatsheets, onboarding docs, or skill references

## Site Copy

Illuminate helps users learn by doing. When a user asks for help with a task, the system turns the objective into a guided walkthrough instead of a one-shot answer. Each step captures the required details, confirms progress, and builds toward a final artifact that can be saved, shared, or reused later.

## Output Artifacts

- SOP
- cheatsheet
- recap document
- training handout
- onboarding walkthrough
- decision record
- process reference
- Knowledge Hub item

## Strategic Role

This is especially valuable because it turns "help me do this" into institutional knowledge.

## Features

- 1:1 guided task sessions
- persona-assisted walkthroughs
- knowledge-level adaptation
- step-by-step completion flow
- required detail capture
- slide-like progress states
- final recap artifacts
- SOP and cheatsheet generation
- export to KnowLedger / Knowledge Hub
