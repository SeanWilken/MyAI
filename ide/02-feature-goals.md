# Feature Goals

## Current Foundation (Implemented / In Progress)

- Browser workspace with file tree, Monaco editing, and save flows.
- Workspace snapshots and recovery primitives.
- Catalog metadata (projects, relationships, file metadata).
- File tagging with category/tags/notes/color.
- Drag-and-drop file move support.
- Right-panel context concepts and graph-oriented UI scaffolding.

## Near-Term Product Goals

- Functional explorer filtering and search with TanStack fuzzy ranking.
- Context cards backed by server data instead of static placeholders.
- Real dependency graph (imports and reverse references) from indexed code.
- Mode-aware workflows for Code, Code Assist, Pair Program, and AIDE.

## Build/Runtime Goals

- Run scripts, tests, and builds in managed containers.
- Offer preset environments and raw base environments.
- Enable optional long-lived personal workbench containers.
- Provide ephemeral task containers for reproducible job execution.

## Automation Goals

- Scheduled test routines (nightly or policy-based).
- Nightly AI code review summaries and risks.
- Morning briefing generation for next-session startup.
- Futurelog capture for roadmap and follow-up incentives.

## Website/Storytelling Goals

- Represent AIDE as one module in the wider MyAI suite.
- Explain how context, runtime, and governance reinforce each other.
- Show clear value for local use, hosted team use, and future native clients.
