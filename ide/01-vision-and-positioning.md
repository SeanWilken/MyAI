# Vision and Positioning

## One-Line Definition

MyAI AIDE is an AI-native developer environment for planning, building, validating, and evolving software across local and hosted runtimes.

## Product Intent

- Keep developers in flow from context to code to verification.
- Blend IDE interactions, AI assistance, and reproducible execution environments.
- Support solo makers and organizations with the same architecture.

## Audience

- Individual developers who want one place to code and collaborate with AI.
- Teams that need governance, repeatability, and reviewable automation.
- Organizations that want hosted environments without losing local flexibility.

## Experience Pillars

- Context-aware development: active context, current scope, patterns, dependencies, concerns, and AI suggestions.
- Reproducible execution: run code, tests, builds in controlled environments.
- Recoverability: reset containers and restore work without platform fragility.
- Cross-app continuity: artifacts and context flow to and from MyAI Core/Studio/Council/KnowLedger.

## Strategic Outcome

Deliver a system where software work can start quickly, stay explainable, and scale from local experimentation to team-grade hosted delivery.
