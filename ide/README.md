# MyAI IDE Strategy Index

This folder is the multi-document source of truth for the MyAI IDE slice (AIDE + runtime services).

It is designed to coordinate product goals, backend capabilities, and website messaging from one place.

## Scope

- Product vision and user outcomes for MyAI AIDE.
- Feature map for current, near-term, and aspirational capabilities.
- Runtime architecture for local and hosted deployment.
- Operational plans for build jobs, periodic checks, and AI review briefings.

## Document Map

- `01-vision-and-positioning.md`: what AIDE is and who it serves.
- `02-feature-goals.md`: prioritized capabilities and maturity targets.
- `03-runtime-and-build-server.md`: environment model, cost strategy, and orchestration.
- `04-operations-and-agent-routines.md`: nightly tests, code review automation, morning brief flow.
- `05-roadmap-phases.md`: phased implementation plan.

## Working Principle

MyAI AIDE should feel like a modern AI-native developer environment while remaining reproducible, resettable, and affordable to run at scale.
